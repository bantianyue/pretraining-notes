MACaQ：逐层独立的 MXFP4 后训练量化

中文精读 ｜ 原文：https://arxiv.org/abs/2611.10649

MACaQ：在线变换留在层内，MXFP4 量化逐层独立，122B 模型 64 分钟量化完（中文精读）

  • 原文：MACaQ: Fast, Model Agnostic Calibrated Quantization for Low-Precision Weights and Activations，Lorenz K. Muller 等，Huawei Computing Systems Lab，arXiv:2611.10649
  • 原文链接：https://arxiv.org/abs/2611.10649
  • 收藏日期：2026-11-16
  • 星级：4⭐
  • 主题：低精度量化 / MXFP4 / PTQ

一句话要点

MACaQ 把在线变换留在层内，让 MXFP4 的 W4A4 后训练量化逐层独立：122B 的 Qwen3.5-122B-A10B 用 32.5GB 显存、64 分钟量化完，WikiText-2 困惑度 5.14（FP16 是 5.06）；Qwen3-32B batch 1 解码 69.8 tok/s，对 FP16 的 22.8 快 3.06 倍。

为什么变换要留在层内

  • 低精度量化的老问题：离群值逼着做在线变换（缩放、旋转），但变换一跨层，量化就得整模型联动，没法逐层独立。
  • MACaQ 的取舍：变换留在层内，每层自己管自己的缩放与旋转，量化流程按层走，显存与时间都随层数线性增长，不随模型总规模爆炸。
  • 代价是每层都要为在线变换付开销：Qwen3-32B 上端到端开销 2.3%，换来的是逐层独立带来的可扩展性。

方法四件套

  • 在线缩放：每层在线算缩放因子，压离群值。
  • 在线微旋转：小角度旋转打散离群方向，比大旋转便宜。
  • Hessian 加权指数选择：用 Hessian 信息选每个权重的量化指数，重要的权重给更精细的表示。
  • Flip-Refinement：22 步伪代码的精修流程，反复翻转、评估、保留更优的量化选择。
  • 消融（Llama-3-8B，WikiText-2 困惑度）：RTN 8.28 → 加 Hessian 指数搜索 8.09 → 加微旋转 7.65 → 加在线第二缩放 7.08 → 加 Flip-Refinement 6.87（512 次翻转，比默认配置的 6.90 还低一点）。

量化速度与精度

  • 122B 模型：Qwen3.5-122B-A10B，51.2 万校准 token、32 次翻转，64 分钟量化完，只用 32.5GB GPU 显存，量化后模型 74GB。
  • 精度：WikiText-2 困惑度 5.14（FP16 5.06）；Llama-3-8B 上 MACaQ 的 Wiki2 6.90 / C4 11.01（FP16 6.14 / 9.46），比 DuQuant++ 与 MR-GPTQ 的最好困惑度低，量化时间还少 11 倍。
  • Llama-3-8B 量化约 150 秒（K=128、20 万校准 token）。
  • FLUX 图像扩散：MACaQ 的 PSNR 15.04 / SSIM 0.697 / LPIPS 0.218，NVFP4 是 14.85 / 0.676 / 0.235——量化方法不只对语言模型有效。

内核与端到端速度

  • 内核级：小层开销至多约 6.4%，大层低于 2%——在线变换的代价随层变大而摊薄。
  • 端到端：Qwen3-32B batch 1 解码 69.8 tok/s 对 FP16 的 22.8（3.06 倍）；batch 256 时 5252.8 对 3061.5 tok/s。
  • 结论：MXFP4 的 W4A4 不是纸面精度，配上在线变换留在层内的设计，解码速度实打实地翻了三倍。

结语

  • MACaQ 的核心取舍是「变换留在层内」：付 2.3% 的在线开销，换逐层独立、64 分钟量化 122B 模型。
  • 四件套里 Flip-Refinement 是最后一块拼图：从 7.08 压到 6.87，说明量化后的精修仍有肉可吃。
  • 对要把大模型压到 MXFP4 落地的人，这篇给了一个可复现的配方：逐层独立的流程、64 分钟的 122B 实测、3 倍的解码加速。
