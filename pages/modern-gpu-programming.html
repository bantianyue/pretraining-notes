0. 一句话总览

mlc.ai 的另一本新书，是《Agentic GPU Programming for MLSys》（知识库 08 号）的姊妹篇：这边讲"人怎么写出高性能 GPU kernel"，那边讲"agent 怎么写"。目标硬件 NVIDIA Blackwell，全书用 TIRx Python DSL 写可运行、可验证的真实 kernel，核心理念：data layout、异步数据搬运、异步协调。

1. 全书结构

  • Part I：Understanding the GPU——GPU 组织与执行模型、写 fast kernel 的通用技术、data layout、异步内存操作与协调。建立全书依赖的硬件直觉；
  • Part II：TIRx Overview——全书代码示例的底座 DSL；
  • Part III：GEMM: Tiled to SOTA——从朴素 tiled GEMM 一步步优化到 SOTA：TMA pipelining → persistent kernel + tile scheduler → warp specialization → 2-CTA cluster → multi-consumer warp specialization，最后端到端实测；
  • Part IV：FlashAttention 4——把 Part III 的技术全部用上：QKᵀ MMA 与 PV MMA、softmax 在线 rescaling、TMEM layout 复用、barrier 协议、pipeline timeline、causal masking、GQA 支持、tile scheduling；
  • Appendices：TIRx 语言参考、可复现的 GPU benchmark + profiling 工作流、编译器内部原理、异步 kernel 调试指南。

2. 关键技术线

  • TMA（Tensor Memory Accelerator）pipelining：Blackwell 硬件异步搬运，软件流水线掩盖访存；
  • Warp specialization：生产者/消费者 warp 分工 + multi-consumer 变体，2-CTA cluster 协同；
  • Persistent scheduling：kernel 常驻、tile 调度器动态分发，解决尾部效应；
  • FlashAttention 4 完整实现：不是伪代码，是可编译验证的 kernel，含 GQA、因果掩码、TMEM 复用。

3. 与知识库其他内容的关系

  • 与 08 号《Agentic GPU Programming》互补：08 号讲"agent 在 TIRx harness 下写 kernel"的方法论，这本讲"kernel 本身怎么写到 SOTA"——同一套 TIRx 底座，两本书合起来就是"人写 kernel 的技艺 + agent 写 kernel 的工程"；
  • 与 GEMM 章（07 号《How to make your models fast》）互补：07 号讲 naive→shared-memory tiled→register tiled 的经典优化阶梯（pre-Blackwell 时代），这本是 Blackwell 时代的续篇：TMA、warp specialization、cluster；
  • 与 Modular《Kernel Optimization》（05 号）互补：那边讲工具阶梯（cuBLAS/TVM/Triton/CUDA/Mojo），这边是 CMU 课程式的系统化教程。
