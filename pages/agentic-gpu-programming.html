0. 一句话总览

ML 系统依赖 fast GPU kernel（attention、GEMM、fused 算子），而写出这些 kernel 需要算法 + 硬件 + 编程模型的深厚功底。这本书讲的是：如何让 coding agent 来干这活——用 compiler 驱动的 harness（TIRx）给 agent 提供表达优化想法、诊断错误、测量性能、沉淀结果的环境，把"agent 写 kernel"变成可重复的工程流程。

1. 全书结构

  • Part I：Agentic GPU 编程的要素——compiler 基础设施与 agent workflow 如何配合做迭代式 kernel 开发；领域专用程序分析、可复用的知识库、benchmark 与 profiling；对比不同 agent workflow，组合成有效的 GPU 优化策略。
  • Part II：TIRx Harness——一个具体的 compiler harness 实例：TIRx 编译器基础 + KCoral benchmark server（执行接口）。
  • Part III：实战——端到端教程。先用 Grouped GEMM 走通 workflow，再用录制的 Kimi Delta Attention（KDA）实战展示诊断与 review，最后是 advanced tips。

2. 实战一：Grouped GEMM（B200）

任务：M-grouped contiguous FP8 GEMM（D_g = A_g B_g^T，各 group 行数不同——MoE 典型形状），以 DeepGEMM 为正确性参照和性能基线，4 种配置（4/8 group，不同矩阵维度）。

流程： 1. 两台机器（可同一台）：agent 机 + 跑 KCoral 的 GPU server（python -m kcoral server --gpus 0）； 2. evolution/setup.py 建任务 worktree（含 PROMPT.md、benchmark 命令、写作规范）； 3. 先跑 baseline（DeepGEMM，确认 4/4 通过）； 4. 启动 agent：goal mode（/goal 让优化目标跨 turn 存活，示例目标：相对基线 3x 加速）或 Flame Chase（两个 agent 轮流 fresh session 接力，24h 预算）。

Agent 每轮：检索相关实现 → 写 candidate kernel → 提交分析 + GPU 实测 → 看反馈决定下一次实验。tile 大小、group 调度、layout、warp 分工、pipeline 都由 agent 自己定；成绩记在 frontier/index.json。

3. 实战二：Kimi Delta Attention（KDA）

更复杂的 attention 变体，用来展示 harness 的深层能力： - Synccheck / Racecheck：同步与访存序错误的编译器分析，agent 据此修复； - profiling 反馈指导下一步优化； - Review：审查 speedup 背后的假设，把发现变成更强的检查、更好的工具、可复用的 kernel。

4. 要素拆解（Part I/II 的核心思想）

  • Compiler-driven harness：agent 不直接面对裸 CUDA，而是面对 TIRx 这样的编译器底座——表达优化想法有载体，错误有结构化诊断，性能有可复现测量。
  • 领域专用程序分析：通用 lint 不够，要的是懂 GPU 语义的分析（同步、竞态、访存序）。
  • 知识库：值得保留的结果沉淀下来，变成下一次搜索的起点（frontier 机制）。
  • Benchmark/Profiling：KCoral 提供隔离、可复现的 GPU 实测环境，preparation/compilation 不计入计时。

5. 与知识库其他内容的关系

  • 这是"用 agent 做 kernel 优化"的方法论——用户（AI 圈的 9527）本人的深域正是 GPU kernel 优化（KernelAgent 系列），且日常就是用 agent（我）做 kernel 相关工作，这本书相当于把这套实践系统化了；
  • 与 Modular《Kernel Optimization》（工具阶梯：Triton/CUDA/Mojo）互补：那边讲"人用什么工具写 kernel"，这边讲"agent 在什么 harness 下写 kernel"；
  • Grouped GEMM / MoE 形状与 MLSysBook 的专家并行、abcdabcd987（二）的 EP=64 讨论直接相关——MoE 的 kernel 实现正是 EP 落地的最后一公里。
