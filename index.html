vLLM 上下文并行部署

原文：Context Parallel Deployment — vLLM（官方文档）

prefill 和 decode 分开设计上下文并行：prefill CP 把长请求的 QKV 按 chunk 分到多卡并行计算，控制首 token 延迟（TTFT）；decode CP 的核心是沿序列维度切分 KV cache，解决张量并行带来的 KV cache 复制问题——比如 DeepSeek-R1 开 -tp 8 会有 8 倍 KV cache 复制，加上 -dcp 8 即可消除。支持 MLA / GQA 模型，可与多 token 预测（MTP）组合。与训练侧的 CP 原理相通（都是沿 sequence 切分），但优化目标不同：训练要吞吐和显存，推理要延迟和 KV cache 利用率。
